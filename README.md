# Python 基础语法学习总纲

本仓库只覆盖 **Python 基础语法**，不涉及面向对象、网络、爬虫、数据分析等进阶内容。

建议环境：Python 3.10+。每章一个独立目录，直接运行对应 `demo.py` 即可：

```bash
python 01_hello_python/demo.py
```

学习方式：先读本章「学什么」，再对照 demo 里的注释动手改一改，最后做章末练习。

## 学习路线（5 个阶段）

### 阶段一：入门与数据（约 3～4 天）

| 章 | 目录 | 学什么 | 建议掌握标准 |
| --- | --- | --- | --- |
| 01 | `01_hello_python` | 注释、缩进、`print`、代码块 | 能独立写出可运行的小脚本 |
| 02 | `02_variables_and_types` | 变量、`int/float/bool/None`、类型转换 | 能判断类型并完成安全转换 |
| 03 | `03_operators` | 算术、比较、逻辑、赋值、成员、身份 | 能写出正确的表达式 |
| 04 | `04_strings` | 索引、切片、常用方法、f-string | 能拼接、格式化、截取字符串 |

### 阶段二：容器类型（约 3～4 天）

| 章 | 目录 | 学什么 | 建议掌握标准 |
| --- | --- | --- | --- |
| 05 | `05_lists` | 增删改查、切片、排序 | 能用列表保存并处理一组数据 |
| 06 | `06_tuples` | 不可变、解包、适用场景 | 知道何时用元组而不是列表 |
| 07 | `07_dicts` | 键值对、遍历、常用方法 | 能用字典表示结构化信息 |
| 08 | `08_sets` | 去重、交并差 | 能用集合做去重和集合运算 |

### 阶段三：流程控制（约 2～3 天）

| 章 | 目录 | 学什么 | 建议掌握标准 |
| --- | --- | --- | --- |

| 10 | `10_loops` | `for`、`while`、`break`、`continue`、`range` | 能遍历数据并控制循环 |

### 阶段四：函数与语法糖（约 2～3 天）

| 章 | 目录 | 学什么 | 建议掌握标准 |

### 阶段五：容错与复用（约 2 天）

| 章 | 目录 | 学什么 | 建议掌握标准 |
| --- | --- | --- | --- |

## 刻意不学（本仓库范围外）

这些内容很重要，但不属于「基础语法」：

- 面向对象：`class`、继承、魔术方法
- 进阶语法：装饰器、生成器、迭代器协议、`async/await`
- 标准库深挖：正则、日期时间进阶、多线程
- 第三方生态：NumPy、Pandas、Flask、爬虫等

打完上面 15 章后再单独开专题。

---

## 推荐顺序与节奏

1. **每天 1 章**：先运行 demo，再自己改 3 处输出，确认理解。
2. **每阶段末复习**：合上注释，凭记忆重写该阶段最小示例。
3. **卡住时**：不要跳章。容器（05～08）和循环（10）是后面所有章节的底座。
4. **完成标志**：能不看文档写出「读取文本 → 统计词频 → 写入结果」的小脚本（会用到 04、07、10、11、15）。
